# Trace documentation DOX

## Purpose

- Own durable records of repository investigation, analysis, planning, review, and operations when those trace categories exist.

## Local Contracts

- Keep each trace in the category matching its purpose and use dated descriptive filenames.
- Preserve evidence provenance and identify the repository revision or time boundary when conclusions depend on it.
- Do not present plans, reviews, or research as execution evidence.
- Add a child DOX file before introducing a new trace category with durable files.

## Child DOX Index

Direct child DOX files:

| Child | Scope |
| --- | --- |
| [operations/AGENTS.md](operations/AGENTS.md) | Completed implementation and process-change audit records. |
| [research/AGENTS.md](research/AGENTS.md) | Codebase research, findings, and decision-oriented assessments. |
